# 🚨 v7.0 Migration & Datenbank-Reset

## Problem: "Provided data is inadequate"

Dieser Fehler tritt auf, wenn die IndexedDB noch Daten aus v6.0 enthält, die mit dem neuen v7.0 Schema nicht kompatibel sind.

## ✅ Lösung: Datenbank zurücksetzen

### Option 1: Im Browser (Empfohlen für Entwicklung)

1. **Dashboard öffnen**
2. **DB Reset Button** im Header klicken (nur in Development sichtbar)
3. **Beide Warnungen bestätigen**
4. App wird zum Onboarding weitergeleitet

### Option 2: Browser DevTools

```javascript
// Öffne Browser-Console (F12)
// Führe aus:
await import('./shared/db/database.js').then(m => m.resetDatabase());
location.reload();
```

### Option 3: Manueller Reset

1. **Browser DevTools öffnen** (F12)
2. **Application** Tab
3. **IndexedDB** → `BasketballPWA`
4. **Rechtsklick** → "Delete database"
5. **Local Storage** → Alle Einträge löschen
6. **Seite neu laden** (Cmd+Shift+R / Ctrl+F5)

## 🔍 Wie erkenne ich, ob Reset nötig ist?

### Symptome:

```
❌ Dashboard lädt nicht
❌ Console-Fehler: "DataError: Provided data is inadequate"
❌ "Failed to load participation" Fehler
❌ Rote Fehler-Badges im Dashboard
```

## 🛠️ Entwickler-Hinweise

### v7.0 Breaking Changes:

```typescript
// ❌ ALT (v6.0)
const team: Team = {
  team_id: uuid(),
  altersklasse: 'U10',  // ⚠️ ENTFERNT
  saison: '2024/2025',  // ⚠️ ENTFERNT
  liga_id: '123',       // ⚠️ ENTFERNT
  // ...
};

// ✅ NEU (v7.0)
const team: Team = {
  team_id: uuid(),
  extern_permanent_id: '...',  // ✅ NEU: Permanente BBB-ID
  // ... permanente Properties
};

const participation: TeamLigaParticipation = {
  id: undefined,  // Auto-Increment
  team_id: team.team_id,
  extern_team_id: '...',  // ✅ Saison-spezifische BBB-ID
  altersklasse: 'U10',
  saison: '2024/2025',
  liga_id: '123',
  ist_aktiv: true,
  // ...
};
```

### Migration-Strategie:

1. **Kein manueller Migration-Code** mehr
2. **Auto-Reset bei Version-Mismatch**
3. **Immer Backup vor Updates**

### Testing:
